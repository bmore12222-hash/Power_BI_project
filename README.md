# Power_BI_project
# E-Commerce Sales Dashboard | Power BI

## 📊 Project Overview

This project is an interactive E-Commerce Sales Dashboard developed using
Microsoft Power BI to analyze sales performance, profitability, product
categories, customers, and payment methods.

The dashboard provides a consolidated view of key business KPIs and helps
identify sales and profit trends across different time periods and product
segments.

## 📌 Key KPIs

- Total Sales: ₹437.8K
- Total Profit: ₹37K
- Total Quantity: 5,615
- Total Orders: 500
- Transaction Records: 1,500

## 🔍 Dashboard Analysis

The dashboard analyzes:

- Monthly Profit Trends
- Sales Performance
- Product Category Performance
- Sub-Category Profitability
- Customer Sales Performance
- Payment Mode Distribution
- Quarterly Performance

## 📈 Key Insights

- Clothing generated the highest quantity sold with 3,516 units.
- COD was the most-used payment mode with 2,456 units.
- The dashboard highlights monthly variations in profitability.
- Sub-category analysis helps identify high- and low-profit products.
- Customer-level analysis helps compare individual sales contribution.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning & Transformation
- Excel/CSV Data

## 🎯 Objective

To transform raw e-commerce transaction data into an interactive business
intelligence dashboard that helps users monitor KPIs and identify
sales and profitability trends.
